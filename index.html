sumu 隱私政策

生效及最後更新日期：2026 年 11 月 12 日

sumu 透過 Meta Graph API，向您有權管理並授權的 Facebook 粉絲專頁發布文字或單張照片。本政策涵蓋在您裝置上執行的本機模式，以及私人 ChatGPT Sites MCP 雲端模式。兩種模式都先提供預覽，再由您明確確認發布。

1. 適用範圍與維護者

本政策適用於 sumu 的 Facebook 粉專發文功能，包括 MoQing Facebook Publish 本機工具，以及供 Dot 等授權客戶端使用的私人 Sites MCP 服務，並由 GitHub 帳號 tls0912 維護。

sumu 不另設網站會員註冊，也不使用「使用 Facebook 登入」。私人雲端模式的身分及存取由 Sites 的擁有者私人存取政策控制；可存取服務不代表已授權發布，每次發布仍須您的明確確認。

2. 處理哪些資料，為什麼需要

  • 粉專 ID、名稱及 Page Access Token：用來確認目標粉專、驗證授權，並執行您要求的發布或查詢操作。Token 是 API 授權憑證，不是您的 Facebook 登入密碼。
  • 您指定的貼文文字及照片：用來預覽內容，並在您確認發布後傳送至 Meta。照片以原始檔案內容上傳；工具不會主動移除照片內的 EXIF 等中繼資料。
  • 雲端身分與操作紀錄：私人雲端模式保存擁有者在該 Site 範圍內的使用者識別碼，以及完整預覽文字、粉專 ID、Graph API 版本、確認與內容及照片的摘要、預覽到期時間和發布狀態，用來限制存取、核對您確認的內容及控制預覽有效期。
  • 發布結果：包括貼文或照片 ID、貼文連結，以及操作狀態，用來顯示結果與查詢已發布貼文。
  • 發布與去重紀錄：本機及雲端模式保存粉專 ID、內容的 SHA-256 摘要及可取得的貼文 ID，用來防止相同內容被重複發布。雲端模式也保存發布狀態及結果，以免結果不明時直接重送。

本工具沒有加入廣告、行為分析或開發者遙測功能，也不讀取好友名單、私人訊息或粉專留言。

3. 資料存放與保護方式

本機模式：使用 Windows 本機設定功能時，粉專 ID 與受保護的 Token 存在 %LOCALAPPDATA%\MoQing\FacebookPublish\credentials.json。Token 使用 Windows 目前使用者的資料保護機制加密，操作時才解密至程序環境；粉專 ID 本身未加密。

本機模式也可由執行環境提供粉專 ID 與 Token。此時環境變數的保存及存取權限由您使用的作業系統或執行環境管理。

本機發布紀錄存於 publications.sqlite3。Windows 預設位於上述資料夾；其他支援的環境預設位於 ~/.local/state/moqing/facebook-publish/。此紀錄未加密，不保存完整正文、照片或 Token。本機草稿、照片及您另行保存的操作輸出由您管理；工具沒有自動刪除這些檔案或本機紀錄的期限。

私人雲端模式：維護者管理的服務端在 Sites 託管的 Cloudflare Workers 上執行。身分、完整預覽文字、預覽期限及發布與去重紀錄存於 D1；單張照片的原始檔案內容存於 R2，包括原檔案內的中繼資料。使用此模式會將這些資料傳送至雲端保存。

雲端 Page Access Token 由 Sites 後端的秘密設定管理，供服務端呼叫 Meta 使用；不放入原始碼、Git、前端程式或對話。私人存取由 Sites 平台控制，發布工具仍要求明確核准。

雲端預覽在建立 24 小時後失效。失效表示不能再用該預覽發布，並不表示正文、照片或紀錄已刪除。雲端草稿及照片目前未設定自動刪除期限；去重紀錄與貼文 ID 持續保存，以防止重複發布及處理結果不明的操作。

若將既有本機去重紀錄透過 Sites 設定移交雲端，移交內容僅包含粉專 ID、內容摘要及可取得的貼文 ID 等去重資料，不包含完整正文、照片或 Token。

4. 資料傳送與第三方服務

  • Meta／Facebook：工具透過 HTTPS 將所需的授權憑證與 API 請求傳送至 Meta。發布時也會傳送您確認的文字、照片及其中的中繼資料。Meta 對資料的處理與保存依其服務條款及 Meta 隱私政策。貼文發布後的可見範圍依 Facebook 粉專及平台設定。
  • 您選用的 AI 助理或執行客戶端：若您在對話中提供文字、照片，或讓助理執行工具，您提供的內容及工具輸出可能由該服務處理。預覽輸出包含完整貼文文字。相關留存與使用方式依您選用服務的政策；本政策不代替該服務的政策。
  • Sites／OpenAI 及其託管基礎設施：私人雲端模式透過 Sites 處理身分與服務存取，並使用 Cloudflare Workers、D1 及 R2 處理或保存上述雲端資料。這些服務供應者依各自的條款及政策處理資料；本政策不代替其政策。
  • GitHub Pages：本政策頁面由 GitHub Pages 提供。頁面本身沒有表單、分析追蹤碼、外部字型或自行設定的 Cookie。GitHub 會為安全目的記錄訪客 IP 位址，詳見 GitHub Pages 資料收集說明及 GitHub 隱私聲明。

維護者不透過本工具出售、出租或提供使用者的憑證、貼文或照片給廣告商。

5. 停止使用、撤銷授權與刪除資料

  1. 停止本機工具使用憑證：移除本機的 credentials.json，並清除您自行設定的粉專 ID、Token 環境變數或其他憑證副本。刪除本機檔案不會使 Meta 已核發的 Token 自動失效。
  2. 停止私人雲端服務使用憑證：中斷客戶端與 MCP 服務的連線，並由服務管理者移除 Sites 後端的 Page Access Token 秘密設定。中斷連線或移除秘密設定不會使 Meta 已核發的 Token 自動失效，也不會刪除已保存的雲端資料。
  3. 撤銷 Meta 授權：在 Facebook 設定的商業整合或應用程式管理中，移除 sumu 的相關授權。實際入口依您的帳號與 Meta 介面而定。
  4. 刪除本機內容及紀錄：您可自行移除草稿、照片、保存的輸出及 publications.sqlite3。移除發文紀錄前，請先確認是否有結果不明的發文；移除後，工具將無法依舊紀錄阻止重複發布。
  5. 請求刪除雲端資料：請使用下方聯絡入口，僅描述要處理的資料類型。預覽失效、移除本機檔案或中斷 MCP 連線都不代表雲端資料已刪除。雲端去重紀錄與貼文 ID 持續保存；移除這些紀錄前須先核對結果不明的發文，以免重複發布。
  6. 刪除 Facebook 貼文：請在 Facebook 粉專刪除已發布的貼文或照片。移除本機或雲端資料、或撤銷授權，不會刪除 Facebook 上已有的內容。Meta 的資料留存依其政策處理。

本機資料由您控制，維護者無法遠端替您刪除。雲端資料的刪除須由服務管理者處理；本政策不承諾預覽失效後自動清除或固定的刪除完成期限。若您曾主動向維護者提供資料，或對資料處理及刪除有疑問，可使用下方聯絡入口提出請求。

6. 聯絡方式

隱私問題及資料處理請求，請透過 sumu 隱私政策專案的 GitHub Issues 聯絡維護者。

此管道需要 GitHub 帳號，且留言內容公開。請僅描述問題類型，不要張貼 Access Token、密碼、身分證明、私人聯絡資訊或未公開的貼文與照片。您無須提供上述資料才能提出一般隱私問題。

7. 政策更新

本政策如有更新，會在此網址發布並修改頁首日期。新增功能若需要其他資料或授權，將在使用該功能前說明。
